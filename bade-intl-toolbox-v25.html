XF Checker

XF Checker runs inside AEM, so it can read AEM references without browser cross-origin blocking.

How to use
1. Drag the XF Checker button below to your Edge bookmarks bar.
2. Open AEM and sign in if needed.
3. Select the bookmarklet while you are on AEM.
4. Paste a page URL, authoring URL, preview URL, or /content/... page path.
5. Results open in a new tab.

Page Basic Info

Scan page source through AEM context and return page metadata, AEM Site type, and an en-us / en-gb hyperlink comparison.

How to use
1. Drag the Page Basic Info button below to your Edge bookmarks bar.
2. Open AEM and sign in if needed.
3. Select the bookmarklet while you are on AEM.
4. Paste a live URL, AEM preview URL, or AEM authoring URL when prompted.
5. A new tab opens with metadata, link audit, and en-gb comparison.
Install bookmarklet

Drag this button to the bookmarks bar:

Page Basic Info

If the bookmarks bar is hidden in Edge, press Ctrl + Shift + B.

2026-7-16 V1

  1. Canonical URL is read from the same page type the user inputs: public URL reads public source; AEM preview URL reads that preview source; authoring/properties/path input reads converted AEM preview source. The Canonical URL field dynamically shows Pass or Fail with a color badge.
  2. Site type is read first from the rendered page source chat-oc-opts meta value; if unavailable, it falls back to AEM property ./siteType.
  3. Links are classified as General Link, FWLINK, AKA Link, or In-Page Link.
  4. Same-page anchor links such as #note-1 are classified as In-Page Link; when input is AEM preview, In-Page links keep AEM preview URL format.
  5. en-gb is loaded automatically and compared with en-us while ignoring locale code differences. FWLINK comparison keeps only linkid number and ignores all following parameters. Link comparison includes Display Text and shows the original localized URL when listing differences. Page Title and Page Description compare en-us with en-gb and show a green/red badge.
