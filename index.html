Bookmarklet Home · Page Basic Info

How to use
1. Drag the Page Basic Info button below to your Edge bookmarks bar.
2. Open AEM and sign in if needed.
3. Select the bookmarklet while you are on AEM.
4. Paste a live URL, AEM preview URL, or AEM authoring URL when prompted.
5. A new tab opens with metadata, link audit, and en-gb comparison.
Install bookmarklet

Drag this button to the bookmarks bar:

Page Basic InfoPopover String Report

If the bookmarks bar is hidden in Edge, press Ctrl + Shift + B. Use Popover String Report on the target live/AEM preview page after the page is fully loaded.

Version

2026-7-31 V2

  1. Added a new Run Popover String Report (Preview Only) button beside the Page metadata title in the generated Page Basic Info report.
  2. Important limitation: this button is designed for AEM preview links only from the Page Basic Info report. For live page checking, open the live page first and run the standalone Popover String Report bookmarklet on the opened live page.
  3. The preview-only button opens the analyzed AEM preview page, waits for page access, polls for rendered .popover__info and .popover__badge triggers, and shows progress status while waiting.
  4. Added a 30-second polling timeout. If no rendered popover trigger is detected, the user can still choose to generate the report anyway.
  5. Kept browser-security fallback messaging so users know to run the standalone bookmarklet manually if automatic execution is blocked.
  6. Popover String Report details:
    1. Scans the rendered DOM for popover_info and popover_badge text references.
    2. Generates separate tables: Popover Info first and Popover Badge Reference second.
    3. Sorts both tables by Description by default so duplicate description groups appear together.
    4. Marks duplicate descriptions as Duplicate (N) and applies group colors to make repeated strings easier to review.
    5. Provides copy buttons for localization investigation: Copy all Popover_info strings, Copy all fixed Popover_info strings, and Copy all Popover strings.
    6. Copy all Popover_info strings copies listed Popover Info title and description values with duplicates removed, keeping original spaces.
    7. Copy all fixed Popover_info strings copies the same listed Popover Info values, removes duplicates, and converts non-standard spaces to normal U+0020 spaces.
    8. Copy all Popover strings copies all listed title, badge, and description values from both tables, keeping duplicates and original space characters.
    9. Validates Popover Info strings for non-standard spaces such as U+202F, U+00A0, U+2007, U+2009, and U+200A.

2026-7-16 V1

  1. Canonical URL is read from the same page type the user inputs: public URL reads public source; AEM preview URL reads that preview source; authoring/properties/path input reads converted AEM preview source. The Canonical URL field dynamically shows Pass or Fail with a color badge.
  2. Site type is read first from the rendered page source chat-oc-opts meta value; if unavailable, it falls back to AEM property ./siteType.
  3. Links are classified as General Link, FWLINK, AKA Link, or In-Page Link.
  4. Same-page anchor links such as #note-1 are classified as In-Page Link; when input is AEM preview, In-Page links keep AEM preview URL format.
  5. en-gb is loaded automatically and compared with en-us while ignoring locale code differences. FWLINK comparison keeps only linkid number and ignores all following parameters. Link comparison includes Display Text and shows the original localized URL when listing differences. Page Title and Page Description compare en-us with en-gb and show a green/red badge.

Bookmarklet Home · Page Size Checker

Run an OCToolKit-style page size overview for en-us and all Intl markets.

How to use
1. Drag the Page Size Checker button below to your Edge bookmarks bar.
2. Open AEM and sign in if needed.
3. Select the bookmarklet while you are on AEM.
4. Paste a live URL, AEM preview URL, AEM authoring URL, or /content/... page path.
5. A new tab opens with all markets, optimized page size, and color-coded PASS/FAIL status.
Install bookmarklet

Drag this button to the bookmarks bar:

Page Size Checker

If the bookmarks bar is hidden in Edge, press Ctrl + Shift + B.

2026-7-17 V1

  1. Uses the same OCToolKit page-size formula: fetches ?wcmmode=disabled&ocdebugs=productpriceshowesi&ocaudit=1, then removes whitespace with html.replace(/^(\s+)|(\s+$)|(\s)+/gm, "").
  2. Uses the standard max limit 1024 KB for every market. Hi-Cap mode is not used.
  3. Audits en-us first, then all Intl markets using the same market lists as Live URL maker.
  4. Designed to run inside AEM author context so it can use the current AEM session.
