Pricing and Terminology Comparator User Guide

Use this standalone Edge DevTools script to compare pricing and terminology across market versions of a Microsoft page.

Before You Start

  • Open Microsoft Edge and sign in if the target staging pages require authentication.
  • Use an en-us pricing page or fragment URL. The URL must contain /en-us/.
  • Allow pop-up windows for the site because the results open in a separate report window.
  • For terminology validation, prepare either comma-separated English terms or JSON/JSON Lines exported from TermStudio.

Run the Script

  1. Open a page on the same site as the pricing URL you want to check.
  2. Open DevTools and select the Console tab.
  3. Paste the complete contents of pricing-terminology-compare.console.js and press Enter.
  4. Enter the en-us pricing URL.
  5. Select a market scope:
    • Basic for a quick core-market check.
    • Full for the standard localization scope.
    • Extended for selected parent and submarket routes.
    • ACOM for the 26 ACOM target markets.
    • BizApps for the 47 BizApps target markets.
    • All 294 markets for the complete market scope.
  7. Paste terminology input, or select Skip terminology to run only the pricing comparison.

Loading Markets

  • Loaded means the market page was retrieved successfully.
  • Use the refresh icon beside one failed market to retry only that market.
  • Use Retry all failed markets to retry every unsuccessful market.
  • Use Continue with X failed markets only when an incomplete report is acceptable.

For staging pages, a failed request often means that the browser session is not signed in. Sign in to the staging site and retry the failed markets.

Use the Report

Pricing

  • Review pricing cards, product titles, displayed values, IDs, and recurring policies across markets.
  • Use the Product ID filter when the page contains multiple products.
  • Export the visible Product ID scope with Export pricing XLSX.

Terminology

  • Use Show issues only to hide references and markets without reported issues.
  • Use the term filter to review one English source term at a time.
  • Use Transpose to switch markets between columns and rows.
  • Expand reference paths only when troubleshooting string alignment.
  • Click Possible inflected match to compare the reference term with the detected form.
  • Use the locate icon to open the market page and focus the matched text when browser security rules allow it.
  • Export the current filtered scope with Export terminology XLSX.

Common Problems

  • The report window does not open: allow pop-ups for the current site and run the script again.
  • Markets show Failed to fetch: confirm that you are signed in and that the Console is open on the same site as the target URL, then retry.
  • The Terminology tab is missing: run the script again and provide at least one valid term or TermStudio record.
  • XLSX export fails: a network or browser security policy may block the spreadsheet component; use CSV or copy the table instead.
  • The locate icon opens a page without highlighting: cross-origin redirects or browser isolation may prevent automatic focus.
